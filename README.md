# Mi Español Niveau 2
Application Vite prête pour Vercel avec reconnaissance vocale espagnole, transcription, score estimé, XP et historique par profil.

## Déploiement
Importer les fichiers dans un dépôt GitHub puis importer le dépôt dans Vercel. Framework: Vite, commande: npm run build, dossier: dist.

## Micro
Autoriser le micro. Le score compare les mots reconnus à la phrase modèle. Il s'agit d'un score pédagogique estimé, pas d'une analyse phonétique clinique.
